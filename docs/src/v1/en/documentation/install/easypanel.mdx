# Easypanel

[Easypanel](https://easypanel.io) is a self-hosted Docker deployment platform, and monetr has a one-click deployment template there, as an alternative to a manual Docker Compose or Kubernetes setup.

[![Deploy on Easypanel][easypanel-btn]][easypanel-deploy]

[easypanel-btn]: https://easypanel.io/img/deploy-on-easypanel-40.svg
[easypanel-deploy]: https://easypanel.io/templates/monetr

To install monetr on Easypanel, click the button above, or open your Easypanel dashboard, search for "monetr" in the template list, and deploy it. Easypanel provisions the monetr app service along with its PostgreSQL and Valkey dependencies automatically.
